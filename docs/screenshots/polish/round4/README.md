# Polish pass, round 4

The screenshots were taken at deviceScaleFactor 2.
`map-legend-closed-desktop.png` is scaled to half size to stay under the
size limit. The measurements behind the new starting design are in
`docs/starter-design.md`.

- `lineage-died-out-start-new.png` (desktop) and
  `phone-died-out-start-new.png` (iPhone 13): when the lineage has died
  out, the Lineage tab and the inspector say so and offer "Start a new
  lineage". Renown, records and titles stay.
- `design-new-lineage-desktop.png`: the design screen when founding again.
  It is titled "Design a new lineage", says what carries over, and has a
  "Back to the map" button.
- `map-legend-closed-desktop.png`: the map legend now starts closed on
  every viewport. The open or closed state is remembered on each device,
  and the tour's map step points to the Legend button.
